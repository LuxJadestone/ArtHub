## 已读取证据

公开预览中打开了约 1、6、12、18、24、28 秒的六张画面；1 秒为空白片头，6 秒为球体、立方体和平面，12 与 24 秒为移动镜头的黑白点阵场景，18 秒为点阵放大图。读取了简介与已加载的公开评论，简介提供了 Runevision 原视频链接和技术章节。全片为 21:40，未阅览完整视频，也未听取或转写音频。原始 YouTube 页面访问返回代理 403；实现依据为公开的原作者仓库，不是对未观看章节的复述。

## WebGL 2 移植

| 阶段 | 数据 / 操作 |
| --- | --- |
| 表面绑定 | 局部 / 表面 UV |
| 屏幕足迹 | `dFdx`、`dFdy` |
| 频率 | UV Jacobian 的最大、最小奇异值 |
| 分形层级 | `floor(log2(spacing))` |
| 图案 | `64 × 64 × 16` R8 3D 纹理 |
| 亮度校准 | 原作者 brightness ramp |
| 层间变化 | 嵌套 Bayer 点集，新增 / 移除点 |
| 阈值 | 亮度、对比度、点径变化、拉伸补偿 |
| 比较模式 | 屏幕 Bayer / 固定表面纹理 |

核心移植保留了原作者的灰阶算法、亮度间距补偿、层级量化、反相点阵和径向补偿。3D 纹理从上游 PNG 栈解码，显式恢复 Unity 的自下而上切片和行顺序。展示场景和相机交互为本项目代码；没有移植原视频中的游戏场景，也未实现上游的 RGB、CMYK 和天空盒功能。

验证平面：相机 yaw=0、pitch=0，曝光=0.55，scale=7，径向补偿关闭，视口720×480；取中央300×200像素区域，统计不接触边界、面积2–999像素的白色连通域中位数。距离4与10时，分形模式为144与151 px²，固定表面模式为68与11 px²。测试验证的是该配置下的近似屏幕尺寸保持，不保证所有曲面、视角或亮度下严格恒定。

限制：斜视方向会压缩点，球面 UV 存在极点畸变，几何边缘的导数会产生局部差异。这里的“分形”是点阵层级的自相似关系，与 Mandelbrot 集绘图不是同一个目录条目。
