# 视频参考与实现边界

来源：[timbercyke《一颗钻石里藏着多少光？》](https://www.bilibili.com/video/BV18YxK6NEPy)，本次检查日期 2026-10-28。

## 实际读取的证据

普通 Chromium 浏览器能够播放未登录的公开 30 秒预览；没有绕过登录、验证码或试看限制。全片显示 69 秒，后续内容未检查。yt-dlp 在页面结构解析阶段失败，公共 API 也返回过风控错误；最终使用正常浏览器播放与截图，而非下载完整视频。

实际打开了约 1、6、12、18、24、28 秒的六张预览截图，覆盖红宝石、祖母绿、蓝宝石。约 6 秒可见珊瑚红、黄色、乳白色的多边形切面；约 18 秒祖母绿呈现深绿内部、多次反射般的细碎明亮切面及地面彩色投影；约 28 秒蓝宝石呈现深蓝、青色和白色切面。不同阶段还展示了平面着色到复杂闪光的变化。时间取自播放器当前时间，为近似定位。未听取或转写音频。

简介：“用Godot制作的3D像素宝石动画”。

已读取加载出的公开评论。作者的统一回复写道：

> 宝石是3d建模，在godot里通过着色器渲染成像素风格，可以实时渲染。本视频制作过程中借助了AI工具，但不是AI生成视频。大家可以随意复刻，之后会继续出3d像素渲染有关好玩的东西

该评论确认了建模、着色器、实时渲染和像素化的方向，但没有给出具体算法。在已加载的简介与评论中未找到项目源码链接；不代表全部评论均无链接。截图和原始页面记录只留在 Git 忽略的 `artifacts/video/`，不随项目发布。

## 独立 Web 实现

- 以凸平面集合构造明亮式、阶梯式和枕形式多面体，无外部模型文件。
- 正交相机逐像素求射线与凸多面体交点；使用折射、菲涅耳近似与全内反射，在晶体内追踪最多 8 次反射。
- RGB 使用稍不同的折射率近似色散，并按光程施加颜色吸收。
- 程序化摄影棚光源、色阶量化、切面描边与低分辨率帧缓冲形成像素风格。
- 地面彩色焦散是随时间变化的图形化近似，**不是物理光子追踪结果**。光源不是原作者的场景。
- 预设参数偏向视觉效果；不声称是矿物精确光学数据或原视频逐帧复刻。紫水晶、钻石是本项目扩展预设，并非对未观看片段的还原。

没有搬运作者的素材、视频或未知许可证代码。渲染器与着色器为本仓库独立实现；第三方工具见 `THIRD_PARTY_NOTICES.md`。
